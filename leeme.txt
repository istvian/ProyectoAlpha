INSTRUCCIONES DE INSTALACIÓN Y EJECUCIÓN

1. REQUISITOS PREVIOS

Antes de comenzar, asegúrate de tener instalado:

- Python.
- Node.js (versión LTS): https://nodejs.org/
- Visual Studio Code.

2. CONFIGURACIÓN DEL BACKEND

PASO 1. Crear el ambiente virtual

Abre una terminal en la carpeta principal del proyecto (donde se encuentra la carpeta backend) y ejecuta:

python -m venv .venv

PASO 2. Activar el ambiente virtual

WINDOWS (PowerShell):

.\.venv\Scripts\Activate.ps1

Si tienes problemas con la política de ejecución, ejecuta primero:

Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

Después, vuelve a activar el ambiente:

.\.venv\Scripts\Activate.ps1

LINUX:

source .venv/bin/activate

Cuando esté activado, aparecerá (.venv) al inicio de la terminal.

PASO 3. Ingresar a la carpeta del Backend

Desde la carpeta principal del proyecto, ejecuta:

WINDOWS:

cd backend\app

LINUX:

cd backend/app

PASO 4. Instalar las dependencias

Ejecuta:

pip install -r requirements.txt

PASO 5. Ejecutar el Backend

Asegúrate de estar dentro de backend/app y tener activado el ambiente virtual.

Ejecuta:

fastapi dev

El Backend quedará ejecutándose.

IMPORTANTE:
NO cierres esta terminal mientras estés utilizando el proyecto.
Para detener el Backend, presiona CTRL + C.

3. CONFIGURACIÓN DEL FRONTEND

IMPORTANTE:
Para ejecutar el Frontend debes abrir UNA SEGUNDA TERMINAL.
No debes cerrar la terminal donde está funcionando el Backend.

PASO 1. Ingresar a la carpeta principal del proyecto

Asegúrate de que la segunda terminal esté ubicada en la carpeta principal del proyecto, donde se encuentran las carpetas backend y frontend.

PASO 2. Ingresar a la carpeta del Frontend

Desde la carpeta principal del proyecto, ejecuta:

WINDOWS:

cd frontend

LINUX:

cd frontend

PASO 3. Instalar las dependencias

Ejecuta:

npm install

NOTA:
Este comando normalmente solo se ejecuta la primera vez o cuando cambian las dependencias.

PASO 4. Ejecutar el Frontend

Ejecuta:

npm run dev

El Frontend quedará ejecutándose. La terminal mostrará la dirección local para abrir la aplicación en el navegador.

IMPORTANTE:
NO cierres esta segunda terminal mientras estés utilizando el proyecto.
Para detener el Frontend, presiona CTRL + C.

4. EJECUCIÓN COMPLETA DEL PROYECTO

Para que la aplicación funcione correctamente, el Backend y el Frontend deben estar ejecutándose AL MISMO TIEMPO.

Debes utilizar DOS TERMINALES DIFERENTES:

TERMINAL 1 - BACKEND

Ubicación: backend/app
Comando: fastapi dev

TERMINAL 2 - FRONTEND

Ubicación: frontend
Comando: npm run dev

ORDEN DE EJECUCIÓN:

1. Abrir la primera terminal en la carpeta principal del proyecto.
2. Crear el ambiente virtual de Python si todavía no existe.
3. Activar el ambiente virtual.
4. Ingresar a backend/app utilizando el comando correspondiente al sistema operativo.
5. Instalar las dependencias si todavía no están instaladas.
6. Ejecutar fastapi dev.
7. Sin cerrar la primera terminal, abrir una SEGUNDA TERMINAL en la carpeta principal del proyecto.
8. Ingresar a la carpeta frontend utilizando el comando correspondiente al sistema operativo.
9. Instalar las dependencias si todavía no están instaladas.
10. Ejecutar npm run dev.
11. Abrir en el navegador la dirección local que aparece en la terminal del Frontend.

RECUERDA:

- El Backend funciona en la primera terminal.
- El Frontend funciona en la segunda terminal.
- AMBAS TERMINALES DEBEN PERMANECER ABIERTAS.
- No ejecutes fastapi dev y npm run dev en la misma terminal.
- Si cierras una de las terminales, el servicio correspondiente dejará de funcionar.

5. DETENER EL PROYECTO

Para detener el proyecto:

1. En la terminal del Frontend, presiona CTRL + C.
2. En la terminal del Backend, presiona CTRL + C.

Con esto, ambos servicios quedarán detenidos correctamente.

FIN DE LAS INSTRUCCIONES
