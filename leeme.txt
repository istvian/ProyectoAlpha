En esta ruta va el ambiente virtual (venv) de python

Para crearlo sigue los siguientes pasos:

1) Abrir una terminal en este directorio
2) escribir python3 -m venv .venv
3) Activar el ambiente

Windows: venv\Scripts\activate

SEGUNDA OPCION Windows: si tienes problemas de politica de ejecucion
   Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
   .\.venv\Scripts\Activate.ps1

Linux: source venv/bin/activate

4) Una vez activado ir a la carpeta backend/app 

cd /backend/app
cd backend\app

5) Instalar las dependencias con este comando

pip install -r requirements.txt

6) Abrir el proyecto con vscode 

code .

7) Ejecutar el proyecto (asegurate de estar dentro de la carpeta /backend/app y dentro del venv)

fastapi dev
